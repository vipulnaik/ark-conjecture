# The entangled-generator counterexample: the F_mid twist-cut is not a necessity

**Status: confirmed by explicit permutation-group construction (n = 33), then measured against the table: 289 of 2,186 rows have μ(n) > recorded B(n).** This note records the construction, the error it exposes, what it breaks, what survives, and the repair list. Written 2026-08-16 during the fb_common.py necessity review; the finding fell out of asking why condition (4)'s F_mid strip is a *necessary* condition.

## 1. The claim that fails

Theorem 3.1 (orbital-evasiveness-notes §3), the SAFE cap in `mu_enumerate_v2.value()` (dmax = q-part × largest divisor coprime to F_mid), fb_common condition (4)'s F_mid-gcd strip, rung B's "twist cut to the odd part of c − 1," and (BCG) clause 4 all rest on one argument: *the cyclic layer Γ₁/Γ₂ carries the block rotation C_{F_mid} and the twist's cyclic part, a cyclic group has a unique subgroup of each order, so the two are pairwise coprime.*

The argument assumes C_{F_mid} is a **subgroup** of the layer. It is only a **quotient** (the block-permutation image). This is the same projection-vs-subgroup error as the historical n = 308 "block counts are q-powers" bug, one level down.

## 2. The construction

Take a class of F blocks of size c fused in the cyclic layer. Let z act as the F-cycle on blocks **with step-multipliers a₁, …, a_F whose product ω = a_F⋯a₁ is a generator of 𝔽_c^\***. Then:

- z^F is the **pure full twist** by ω (block image trivial), so the block stabiliser induces all of 𝔽_c^\* on each block: the class's intra-orbital is the single class F·C(c,2) — **full twist, no cut**;
- ⟨z⟩ ≅ C_{F(c−1)} is cyclic; the layer's unique order-2 subgroup is ⟨z^{F(c−1)/2}⟩ = the pure −1 twist, *not* the swap — the swap exists only entangled inside high-order elements, so nothing ever competes for the layer's 2-part;
- foreign parts and an odd top prime q attach exactly as in Part E: conjugation by a top element is a single power map on the layer, and its exponent conditions (≡ 1 on the class component, ≡ mult_h mod r on the foreign component) are CRT-independent.

**Three explicit groups now verify this, two of them at table rows.**

**n = 78 = 6×13, top trivial** (the smallest exceedance, and a composite non-prime-power F): z = 6-cycle on blocks with step-multipliers (2,1,1,1,1,1), product 2 a generator of 𝔽₁₃^*; z has order 72, layer C₇₂ cyclic, Γ₂ = 𝔽₁₃⁶. Computed orbital sizes **{468, 507, 1014, 1014}**: intra 468 = 6·C(13,2) as a single class, within-class cross classes 3·13² and 6·13² exactly as the value formula predicts. **m\* = 468 > B(78) = 465**, so μ(78) ≥ 468 and the recorded row is wrong outright.

**n = 105 = 2×29 + 47*, q = 23** (a flagged table row with a foreign part): entangled swap with multiplier product 2 (a generator of 𝔽₂₉^*), foreign 47-block with multiplier 4 of order 23 on top; layer C₅₆ × C₄₇ ≅ C₂₆₃₂ cyclic. Computed orbital sizes **{812, 841, 1081, 2726}**: intra 812 = 2·C(29,2) full, foreign 1081 = orb(47, 23) = C(47,2). **m\* = 812 > B(105) = 506**, ratio 1.605, exactly the rescan's prediction.

**n = 33 = 2·13 + 7, q = 3** (the prototype) (built as a permutation group, closure computed): |Γ₂| = 169; Γ₁/Γ₂ cyclic of order 168 generated by a single element zu; Γ/Γ₁ ≅ C₃; **orbital sizes {21, 156, 169, 182}**. The fused intra-orbital is 156 = 2·C(13,2) — full twist — where the rung-B rule caps the configuration at 2·orb(13, 3) = 78. The group admits **no** q = 2 chain (the foreign translations C₇ and the foreign 3-twist do not commute, so Γ₁′/Γ₂ would be nonabelian), so no chain reading satisfies Theorem 3.1's coprimality clause: **Theorem 3.1 is false as stated.**

Generators for independent re-verification (points 0–12, 13–25, 26–32): t₁ = x↦x+1 on block 1; t₂ likewise on block 2; z = (x ↦ 2x: B₁→B₂, x ↦ x: B₂→B₁), fixing the foreign part; u = y↦y+1 on 𝔽₇; h = y↦2y on 𝔽₇.

## 3. What breaks

1. **μ(n) ≤ B_safe(n) fails on the computed table.** Rescoring every row's shape space with the corrected cap (full twist on cyclic-fused classes, Lemma C's foreign strip retained), **289 of 2,186 rows** admit configurations exceeding the recorded B(n), ratios up to 1.889 (n = 253: 2783 → ≥ 5256 on 2×73 + 107\*). Full list in `entangled_exceedances.txt`. These are honest per-q scores, not screening artifacts.
2. **The table floor moves.** n = 1817: 75,466 → ≥ 97,920 (3×256 + 1049*, q = 131), density 0.045742 → ≥ 0.0594. Twelve of the 18 tail rows below 1/16 are exceeded. The floor conjecture δ ≥ 1/25 only strengthens (B rises), but "0.045742 at n = 1817" and the record-mechanism prose expire.
3. **The S4 census story reverts.** 15 of the 16 S4 winners (all but 1529) are exceeded by entangled S7-at-F=2 readings — the SAFE "tightening" that resurrected S4 was unsound.
4. **fb_common condition (4) is anti-permissive**, so both collapse certificates (`fallback_cert.py`, `wide_cert.py`) may discard real candidates: their "empty candidate list" proofs are void until the F_mid-gcd strip (fb_common lines ~560–564 and the parallel strip in `single_part_ok`/`multi_part_ok`) is removed and the runs repeated. The 90,299-value collapse claim and μ = B attainment claims inherit this.
5. **Ceiling table §3.3.5, classes 7 and 15 mod 24: 1/9 → 1/8.** Freeing c mod 4 lets n ≡ 7 (mod 8) reach r ≡ 5 (mod 8) (v = 2, η₂ = 1/2) at F = 2, and neither class has the ℓ = 3 cut, so cap₂(1/2) = 1/8 beats the F = 4 reading's 1/9. **Classes 11 and 23 are unchanged** (the ℓ = 3 obstruction is untouched and the mod-8 arithmetic at n ≡ 3 (mod 8) gives the same v = 2), so the global constant 7 − 4√3 survives. All other classes: unchanged (verified residue by residue; the mod-8 improvement matters only where c ≡ 3 (mod 4) previously forced the *worse* r residue).
6. **(BCG) clause 4 (c ≡ 3 mod 4) is unnecessary**; §3.3.4a's congruence chains need rewriting as "best of two residues" rather than forced; rung B's description changes from "twist cut to the odd part" to "full twist available at every c."
7. **`mu-theta-n2-note.md`** rests on the mod-24 apparatus and the attainment claims; it needs review before any arXiv submission.

## 4. What survives

- **Lemma C's foreign strip.** Its proof is a conjugation argument on the r-primary component of the layer, which is a genuine subgroup (the foreign translations), independent of how rotations embed. Applied in the rescan above.
- **All lower bounds**: `ladder_verify.py`'s families understate (twist cuts make them conservative), so the 10⁶ floor 0.04453 and the 1/25 conjecture stand and strengthen.
- **F_mid-vs-foreign shares** remain dominated (the coupling kills the foreign twist: orb(r, 1) = r < B), and **F_mid-vs-F_mid shares** remain harmless in range (audit_fmid.py, run before this finding; its conclusion is unaffected since entanglement only raises the *twist*, which that audit's two candidates already received in the optimistic pass).
- **The global asymptotic constant 7 − 4√3** and the extremal classes 11, 23 mod 24.
- Parts A–D, G.1, the value formula's term structure, Prop. F.1, G.4 (none of these use the coprimality clause).

## 4b. Enumerator cross-check

`me_v3draft.py` (a patched `mu_enumerate_v2.py`: SAFE cap = F·C(c,2) with no F_mid strip; F_mid values dropped from the coprimality list, foreign duplicate test kept) was run on the 16 smallest flagged rows plus three unflagged controls. Every flagged row rises to ≥ the rescan's value — and above it at n = 207 (recorded 2277, scan 2352, patched 2525 via 2×53 + 101*) and n = 231 (recorded 2162, scan 2664, patched 2943 via 2×61 + 109*), where the full search finds better entangled configurations than the shape-restricted scan — while all three controls (260, 273, 306) are unchanged. Monotonicity is structural: the patch only loosens caps and widens admissibility, so no recorded value can fall. The 289-row exceedance list is therefore a list of **lower bounds** on the corrected B; exact new values need the rebuild.
